# rdr-elements

Les fichiers des custom elements de routedurhum.com, servis par GitHub Pages
à une adresse stable, pour qu'un snippet d'en-tête du site les définisse
avant le runtime de Wix. Ils sont déjà servis publiquement par Wix : rien ici
n'est secret.

Source et documentation : dépôt privé `route-du-rhum`,
`docs/RECHERCHE-CHARGEMENT-CUSTOM-ELEMENTS.md`. Ne pas éditer ici : les
paquets sont assemblés depuis `route-du-rhum/src/public/custom-elements/`.

| Paquet | Contenu |
| --- | --- |
| `test-rdr.js` | banc du chargement précoce sur TEST RDR26 : rdr-menu-actus, rdr-menu-cartes |
